1. Email Security: SPF, DKIM, and DMARC

These three protocols work together to protect email. Their roles are commonly confused — here's how to tell them apart.

Where you got tripped up

When a question asks "who is authorized to send" → SPF. When it asks "verify the signature" → DKIM. When it asks "what happens to the message" or mentions disposition → DMARC. The word disposition is DMARC's keyword.

2. Federation vs. Single Sign-On (SSO)

You mixed these up three times. They sound similar but work at different scopes.

Federation

  • Crosses organizational boundaries
  • Uses a trusted third-party identity provider
  • "Log in with Google" on a non-Google site
  • Two separate orgs sharing trust
vs

SSO (Single Sign-On)

  • Works within one environment
  • One login unlocks multiple internal services
  • Log into your company portal, get access to email + HR + intranet
  • Same org, many apps
Memory hook: If the question mentions a third-party or another organization's credentials → Federation. If it mentions one login for many internal services → SSO.

3. 802.1X Authentication

IEEE 802.1X is port-based Network Access Control (NAC). It appeared on all three exams. You need to recognize its vocabulary instantly.

Supplicant
(the client device)
→
Authenticator
(switch or AP)
→
Authentication Server
(RADIUS / LDAP / AD)
Key facts
  • Purpose: Devices don't get network access until they authenticate.
  • Backend: Needs a centralized auth database — LDAP, RADIUS, TACACS+, or Kerberos.
  • Keywords on the exam: "Supplicant" and "authenticator" = 802.1X, always. You'll never see those terms in any other context.
  • Use case: "Each user authenticates with corporate credentials on the wireless network" = configure 802.1X on the APs.

LDAP (Lightweight Directory Access Protocol)

LDAP is the most common backend for 802.1X and any centralized authentication. It's an open protocol for querying a directory of users, passwords, and permissions. Every time a question asks about "validating credentials" against a centralized system, think LDAP (or RADIUS/Kerberos).

EAP (Extensible Authentication Protocol)

EAP is the authentication framework used by 802.1X. It supports many methods (EAP-TLS, PEAP, etc.). If a question mentions EAP, it's in the context of 802.1X network authentication.

5. Security Control Categories

You confused deterrent, detective, and directive multiple times. Here's the complete set:

CategoryPurposeExamples
PreventiveStops the attack from happeningFirewall rules, door locks, encryption
DetectiveIdentifies that an attack is happening or has happenedIDS/IPS, security cameras, log monitoring
DeterrentDiscourages the attacker (doesn't stop them)Warning banners, posted signs, security lighting
CorrectiveFixes things after an attackRestoring from backup, patching
CompensatingAlternative when the primary control isn't feasibleExtra logging when you can't encrypt legacy data
DirectiveTells people what they must do (policy-based)Acceptable use policies, compliance requirements
The trap: deterrent vs. directive

Both are "soft" controls. The difference: a deterrent discourages ("you are being monitored" banner). A directive instructs ("you must change your password every 90 days" policy). Deterrent = discourages. Directive = instructs.

Login banners are deterrents — they discourage unauthorized access by warning people they're being watched.

Quick test

Ask yourself: does it watch? → Detective. Does it block? → Preventive. Does it scare? → Deterrent. Does it tell you what to do? → Directive. Does it fix? → Corrective.

Decision tree

"Personal phone used for work" → BYOD (employee owns it).

"Company needs to manage and standardize, but allow personal use" → COPE (company owns it, personal use allowed).

"Company buys it, employee picks which one" → CYOD.

MDM (Mobile Device Management) is not a deployment model — it's the tool used to manage devices regardless of model. MDM handles remote wipe, policy enforcement, app management, etc.

9. Data States

Data exists in three states. You missed a transit question by confusing it with in-use.

StateWhere the data isExamples
In-transitMoving across a networkEmail being sent, data crossing an 802.1Q trunk, IPS inspecting live traffic
At-restSitting on a storage deviceFiles on a hard drive, data in a database, backup tapes
In-useBeing processed in memory (RAM/CPU)App decrypting credit cards for validation, ATM checking a PIN, spreadsheet recalculating
The IPS trap

"An IPS removes attack frames from the network" — sounds like the IPS is using the data, but the data is moving across the network wire. It's in-transit. In-use means the data is actively loaded into a device's memory for processing, not just flowing through.

12. Cryptography Essentials

Digital Signatures and Trust

You knew a CA signs certificates but still picked the wrong answer. Lock in the chain:

You generate a key pair
→
Submit CSR to CA
→
CA signs your cert
(digital signature)
→
Others trust you because they trust the CA

A digital signature is what adds trust to a certificate. The CA hashes the certificate, encrypts the hash with the CA's private key, and attaches it. Anyone who trusts the CA can verify the signature with the CA's public key.

Integrity vs. Authentication vs. Confidentiality

GoalWhat it meansAchieved by
IntegrityData hasn't been tampered withHashing, digital signatures
AuthenticationProving who you arePasswords, biometrics, certificates
ConfidentialityOnly authorized people can read itEncryption (symmetric or asymmetric)
Non-repudiationCan't deny you did itDigital signatures (prove sender identity)
Digital signatures on email

A digital signature on an email proves integrity (the message wasn't changed), not authentication (who you are). The signature is a hash — it's a tamper seal, not a login credential.

Certificate Validation

MethodFull NameHow it works
CRLCertificate Revocation ListA published list of revoked certificates. Clients download and check it.
OCSPOnline Certificate Status ProtocolClient asks the CA in real-time: "Is this cert still valid?"
OCSP Stapling—The server asks the CA, caches the answer, and staples it to the TLS handshake. Clients don't have to contact the CA themselves.
Memory hook: OCSP stapling = the server does the homework so clients don't have to. "Minimize certificate status checks to the CA" = OCSP stapling.

Password Protection

TechniqueWhat it does
HashingOne-way function. Converts password to a fixed-length digest. Can't reverse it.
SaltingAdds random data to the password before hashing. Makes each hash unique, defeats rainbow tables.
Key stretchingRuns the hash function many times to make brute force slower (bcrypt, PBKDF2).

13. Network Devices and Appliances

You mixed up IPS, WAF, proxy, and other devices on the matching questions. Here's the cheat sheet:

DeviceFull NameWhat it does
IPSIntrusion Prevention SystemMonitors network traffic for known exploits (SQL injection, buffer overflow) and blocks them
WAFWeb Application FirewallInspects user input to web applications. Blocks bad input (SQL injection, XSS) at the application layer
Proxy (Forward)—Sits between users and the internet. Intercepts outbound requests. Caches, filters, monitors.
Reverse Proxy—Sits in front of your servers. Handles inbound traffic from the internet.
Load Balancer—Distributes traffic across multiple servers for redundancy and performance.
Jump Server—A hardened intermediary for admins to connect through before reaching sensitive systems.
Router—Forwards packets between different networks/VLANs using IP addresses.
SIEMSecurity Information and Event ManagementAggregates logs from many sources, correlates events, generates alerts. Not a network device — a monitoring platform.
UTMUnified Threat ManagementLegacy all-in-one security device: firewall + antivirus + content filter + IDS in one box.
NGFWNext-Generation FirewallModern firewall with deep packet inspection, application awareness, IPS built in.
IPS vs. WAF

Both can block SQL injection. The difference is where they work. IPS = network traffic level (packet inspection). WAF = application input level (form fields, URLs). If the question says "evaluate input to a browser-based application" → WAF. If it says "block exploits on the network" → IPS.

Forward vs. Reverse Proxy

Forward proxy = monitors outbound traffic (users → internet). "Monitor all outbound connections for malware" = forward proxy.

Reverse proxy = monitors inbound traffic (internet → your servers).

14. Cloud Concepts

Hybrid Cloud

The main risk of a hybrid cloud (mix of private and public clouds) is network protection mismatches — different security controls, different auth policies, different permissions across providers. Inconsistency is the enemy.

Responsibility Matrix

A cloud responsibility matrix is a visual chart showing what the cloud provider handles vs. what the customer handles. The split changes by service model:

ModelProvider handlesYou handle
IaaS (Infrastructure as a Service)Hardware, networking, virtualizationOS, apps, data, security config
PaaS (Platform as a Service)Everything below + OS, runtimeApps, data
SaaS (Software as a Service)Almost everythingData, user access

SD-WAN (Software-Defined WAN)

When you're connecting to multiple cloud providers, SD-WAN efficiently routes traffic across all of them. A site-to-site VPN works point-to-point, but doesn't scale well to many providers.

Memory hook: One destination = VPN. Multiple cloud providers = SD-WAN.

Orchestration vs. Automation

Automation = one system does a task automatically. Orchestration = multiple systems are coordinated together automatically. A script that converts an email to a ticket and routes it to the right department = orchestration (email system + ticketing system + routing).

Firewall rule tips

When reading firewall rules, always check three things: (1) the protocol and port, (2) the destination IP, and (3) allow vs. block. On C1, you got tricked because RDP (3389) was allowed — but only to a different IP than the question asked about. The implicit deny blocks everything not explicitly allowed.

Implicit deny: If no rule matches the traffic, it's blocked. This is the default on any properly configured firewall. If you don't see a rule for a port/protocol, the answer is BLOCKED.

Keyloggers and Beaconing

Intermittent outbound connections from workstations to one external IP at random times = malware phoning home. A keylogger captures keystrokes and periodically transmits to the attacker. This pattern (random, outbound, one destination) is classic C2 beaconing behavior.

Vulnerability Scan Results

ResultMeaning
False positiveScanner flags something that isn't actually a problem (e.g., JRE vuln when JRE isn't installed)
False negativeScanner misses something that is a real problem (vuln exists but scan shows all clear)

Server Hardening

Hardening = configuring a system securely. Removing defaults, disabling unnecessary services, fixing permissions, tightening SSL. Different from patching, which updates the software itself. If an audit finds configuration issues (defaults, wrong accounts, bad certs), the fix is hardening, not OS updates.

Wireless Security

MAC filtering can be easily bypassed by spoofing a legitimate MAC address. It's not real security — just a speed bump. To actually secure a wireless network, enable WPA3 encryption (or at minimum WPA2 with 802.1X). WPA3 provides cryptographic authentication that can't be spoofed.

Air Gap

An air gap is a physical network separation. No cables, no wireless, no connection of any kind. When a question says "prevent ALL communication" between systems, the answer is air gap. Firewalls and VLANs filter or segment traffic, but a path still exists. Air gap = no path at all.

High Availability (HA)

HA means the service stays up and running. A UPS (Uninterruptible Power Supply) provides HA by keeping systems powered during outages — battery backup or generator. If the question asks what provides HA and lists a UPS, that's the answer.

Dependencies in Change Management

A dependency exists when one change can't happen until another is completed. "App upgrade is delayed because a driver needs to be installed first" = dependency. Not a legacy application (that's old unsupported software).

Enumeration

Enumeration = cataloging hardware and software on a device. If a laptop is enumerated at each login, the system can detect hardware changes and alert the security team. It's an inventory check, not VLAN assignment or MFA.

Host-Based vs. Network-Based Tools

If a device is bypassing the corporate network (using a cellular hotspot), all corporate network tools (UTM, WAF, NGFW) are blind. The only evidence lives on the device itself:

  • HIPS — Host-based Intrusion Prevention System
  • Host-based firewall logs

Both start with "host-based" — when the device isn't on your network, that's the pattern.

18. Test-Taking Patterns

Stop second-guessing yourself

A common pattern on practice exams: your first instinct is correct but you second-guess yourself and change to the wrong answer. This is especially common with terms like MOA, deterrent, false negative, digital signature, and data custodian — where the right answer "feels too simple."

Rule: Unless you can articulate a specific reason your first answer is wrong, don't change it. "Maybe it's the other one?" is not a reason.

Read for keywords

Many questions have a single word that points directly to the answer:

  • "Disposition" → DMARC
  • "Supplicant" → 802.1X
  • "Broad formal agreement" → MOA
  • "Confidential / Secret" → Mandatory Access Control
  • "Third-party credentials" → Federation
  • "Prevent ALL communication" → Air gap
  • "Personal phone for work" → BYOD
  • "Preserve data for court" → Legal hold
Your strongest areas

If you're using this guide, you likely already have a solid foundation in attack identification, physical security, authentication factors, and cryptography. The gaps covered here are conceptual distinctions between similar terms — not fundamental knowledge holes. Drilling these distinctions is what pushes a 75% to a pass.
